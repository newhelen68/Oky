## 📄 Ejemplo 1: Política de Trabajo Remoto

```
POLÍTICA DE TRABAJO REMOTO
TechCorp Inc.

1. INTRODUCCIÓN

Esta política establece las directrices para el trabajo remoto en TechCorp Inc. 
El objetivo es proporcionar flexibilidad a los empleados mientras se mantiene 
la productividad y la colaboración del equipo.

2. ELEGIBILIDAD

Son elegibles para trabajo remoto:
- Empleados con más de 6 meses de antigüedad
- Roles que no requieran presencia física obligatoria
- Evaluación de desempeño satisfactoria

3. HORARIOS

- Horario flexible entre 7:00 AM y 7:00 PM
- Mínimo 4 horas de disponibilidad en horario core (10:00 AM - 3:00 PM)
- Reuniones obligatorias según calendario del equipo

4. EQUIPAMIENTO

La empresa proporciona:
- Laptop corporativa
- Monitor adicional (opcional)
- Silla ergonómica (reembolso hasta $300)
- Subsidio de internet: $50/mes

5. SEGURIDAD

- VPN obligatoria para acceso a sistemas
- Contraseñas seguras y autenticación de dos factores
- No compartir dispositivos corporativos
- Reportar incidentes de seguridad inmediatamente

6. COMUNICACIÓN

- Slack para comunicación diaria
- Zoom para reuniones
- Email para comunicaciones formales
- Respuesta esperada en 2 horas durante horario laboral

7. EVALUACIÓN

El trabajo remoto se evaluará trimestralmente basándose en:
- Productividad y cumplimiento de objetivos
- Calidad del trabajo
- Comunicación efectiva
- Participación en actividades del equipo

Fecha de vigencia: 1 de enero de 2024
Revisión: Anual
```

**Preguntas de prueba:**
- "¿Quiénes son elegibles para trabajo remoto?"
- "¿Qué equipamiento proporciona la empresa?"
- "¿Cuál es el horario core obligatorio?"
- "¿Cuánto es el subsidio de internet?"

## 📄 Ejemplo 2: Guía de Producto - SmartWatch Pro

```

- Giroscopio
- GPS + GLONASS
- Brújula digital

1. Descarga la app "SmartWatch Pro" desde:
   - iOS: App Store
   - Android: Google Play

2. Activa el Bluetooth en tu teléfono

3. Abre la app y sigue los pasos:
   - Crear cuenta o iniciar sesión
   - Seleccionar "Agregar dispositivo"
   - Mantén presionado el botón lateral del reloj (5 segundos)
   - Selecciona "SmartWatch Pro X1" en la lista

4. Personaliza tu perfil:
   - Edad, altura, peso

- Auto-detección de ejercicios

- Cálculo de VO2 max

- Llamadas entrantes
- Mensajes (SMS, WhatsApp, etc.)
- Emails
- Apps sociales
- Calendario

Uso típico: 3 días
- Modo ahorro: hasta 7 días
- GPS continuo: 20 horas

CARGA

1. Conecta el cable magnético al puerto trasero
2. Conecta el USB a una fuente de alimentación
3. Tiempo de carga completa: 2 horas

RESISTENCIA AL AGUA

IP68 y 5ATM:
- Salpicaduras: ✓
- Ducha: ✓
- Natación: ✓ (hasta 50m)
- Buceo: ✗
- Agua caliente: ✗

Problema: No sincroniza
Solución: Verifica Bluetooth, reinicia la app, desempareja y vuelve a emparejar

Problema: Batería se descarga rápido
Solución: Reduce brillo, desactiva GPS continuo, cierra apps no usadas

Email: support@smartwatchpro.com
Teléfono: 1-800-SMART-01
Chat: Disponible 24/7 en la app
```

## 🎯 Cómo Usar Estos Ejemplos

### Método 1: Crear PDF
1. Copia el texto de cualquier ejemplo
2. Pégalo en Microsoft Word o Google Docs
3. Formatea como desees
4. Exporta como PDF
5. Sube al sistema RAG

### Método 2: Crear DOCX
1. Abre Microsoft Word
2. Copia y pega el contenido
3. Guarda como .docx
4. Sube al sistema RAG

### Método 3: Múltiples Documentos
1. Crea los 3 documentos por separado
2. Súbelos todos al sistema
3. Haz preguntas que requieran información de diferentes documentos
4. Ejemplo: "¿Qué productos menciona el informe financiero?"

---

## 💡 Tips para Mejores Pruebas

1. **Varía el contenido:**
   - Mezcla documentos técnicos y de negocios
   - Usa diferentes formatos (listas, tablas, párrafos)

2. **Prueba edge cases:**
   - Documentos muy cortos (< 500 caracteres)
   - Documentos muy largos (> 50 páginas)
   - Documentos con muchas tablas

3. **Preguntas difíciles:**
   - Requieren información de múltiples secciones
   - Comparan datos entre documentos
   - Preguntan sobre cosas NO en los documentos

4. **Evalúa la calidad:**
   - ¿La respuesta es precisa?
   - ¿Cita las fuentes correctas?
   - ¿El porcentaje de similitud tiene sentido?
